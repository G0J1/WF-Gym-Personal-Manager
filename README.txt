This application is a personal tracker for gym progress.

The dashboard screen lets the you see your planned workout and goals for the day.
The workout builder lets you set targets for exercises.
The active workout form allows you record your actual performance and features a timer for time-based exercises such as planks.
The progress tracker allows you to track your progress over time through charts and statistics.


The following NuGet packages were used and may require downloading:
	Microsoft EF Core
	ScottPlot

To run:
	Open the solution in Visual Studio
	Download packages if required
	Press the Run button to launch
